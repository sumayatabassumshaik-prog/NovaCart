# 🛍️ NovaCart — Mini E-Commerce Web App

NovaCart is a modern, responsive mini e-commerce website built using HTML, CSS, and JavaScript. It provides an interactive shopping experience with product browsing, wishlist management, a shopping cart, and a checkout preview.

## ✨ Features

- 🛒 Dynamic product catalog
- 🔍 Product search
- 🏷️ Category-based filtering
- ↕️ Product sorting
- ❤️ Wishlist functionality
- ➕ Add and remove cart items
- 🔢 Increase or decrease product quantities
- 💰 Automatic price and delivery charge calculation
- 💾 Cart and wishlist saved using Local Storage
- 💳 Checkout preview modal with form validation
- 📱 Responsive design for desktop and mobile
- 📧 Newsletter signup demo

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Responsive Web Design

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Explore products and test the shopping features.

## 📁 Project Structure

```text
NovaCart/
├── index.html
├── style.css
└── script.js
```

## 🎯 Project Objective

The objective of NovaCart is to demonstrate front-end web development skills by creating an interactive shopping interface with dynamic product rendering, cart management, and responsive UI design.

## ⚠️ Note

This is a front-end demonstration project. Checkout does not process real payments, and newsletter signup does not send emails to a server.
